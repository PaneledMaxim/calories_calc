# Calorie Tracker

Учебный Django-проект для учета питания и калорий.

## Возможности

- Регистрация, вход и выход пользователя.
- Профиль пользователя с ростом, весом и возрастом.
- Список пользователей и друзья.
- Продукты с калориями и БЖУ.
- Дневник питания с подсчетом калорий.

## Запуск проекта

1. Установить Django:

```powershell
pip install django
```

2. Применить миграции:

```powershell
python manage.py migrate
```

3. Запустить сервер:

```powershell
python manage.py runserver
```

4. Открыть сайт:

```text
http://127.0.0.1:8000/
```

## Основные приложения

- `accounts` — пользователи, профиль, друзья, восстановление пароля.
- `products` — продукты и их пищевая ценность.
- `diary` — дневник питания.

## Примечания

Письма восстановления пароля сохраняются в папку `sent_emails`.
